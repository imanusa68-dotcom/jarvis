## Запрос мейнтейнера

«Сделай возможность скопировать текст в диалоге (надоело переписывать вручную) — и чтобы
вставка в поле работала.»

## Причины (в коде)

- Лог диалога `self.log_text` был `state="disabled"` → нельзя выделить/скопировать.
- `Ctrl+C/V` в tkinter привязаны к латинским keysym → на РУССКОЙ раскладке не срабатывают.

## Реализовано (2026-07-05)

- Лог теперь **read-only, но выделяемый**: держим `state="normal"` (disabled-Text нельзя
  выделять), а ввод символов блокируем (`_make_readonly`). Убраны прежние переключения
  `state` в typewriter-выводе.
- **`_enable_clipboard(widget, editable)`** — Ctrl+C/V/X/A по ФИЗИЧЕСКОЙ клавише
  (`event.keycode`: C=67,V=86,X=88,A=65) + запасной путь по кириллическим keysym
  (с/м/ч/ф) → работает на русской раскладке. Генерит `<<Copy>>`/`<<Paste>>`/`<<Cut>>`.
- **`_attach_menu`** — правый клик: Копировать / (Вставить) / Выделить всё.
- Подключено к: лог (copy + select-all), поле ввода (всё), поле API-ключа (вставка ключа).

## Проверка

Смоук (withdrawn Tk): лог выделяется и `<<Copy>>` кладёт реальный русский текст в буфер;
select-all в поле; все Ctrl-/правоклик-привязки на месте. Полный `pytest` — 145 passed
(ui.py тестами не покрыт, регрессий нет). Живой Ctrl+V на раскладке — подтвердит мейнтейнер.
