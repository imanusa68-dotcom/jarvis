## Живой репро (2026-07-04)

«какой последний файл на загрузки» → `resolve_reference downloaded_file` → **«Не нашёл
недавно скачанного файла»**; через `system_context` → «за последние 5 минут изменений не
обнаружено». Причина: резолвер знает только события ЗА СЕССИЮ (журнал), а уже лежащий
новейший файл в папке не видит.

## Agent Brief

**Category:** bug
**Summary:** `downloaded_file`/`recent_file` смотрят только журнал событий сессии → «последний файл в Загрузках» не работает, если ничего не менялось при запущенном Джарвисе. Добавить холодный фолбэк «новейший файл в папке по mtime».

**Current behavior:**
`resolve("downloaded_file")` = новейшее created-событие под Downloads ИЗ ЖУРНАЛА. Журнал
пуст (файл лежал до запуска) → not_found. Нет способа спросить «новейший файл в папке X».

**Desired behavior:**
- `downloaded_file`: сначала журнал (как сейчас); если пусто → **посмотреть реальную папку
  Загрузки** и вернуть новейший файл по времени изменения (mtime), пропуская временные
  файлы (`~$`, `.tmp`, `.crdownload`, `.part`). НЕ использовать время доступа (DateAccessed).
- Новый kind **`newest_in_folder`** (hint = имя папки: downloads/documents/desktop/…) →
  новейший файл в указанной личной папке. Ровно отвечает «последний файл в <папке>».
- Читать содержимое НЕ нужно; смотреть только метаданные одной папки (дёшево). Границы —
  только личные папки через `_known_folders`.
- Не ломать существующее: journal-first порядок сохранить; тесты 004 зелёные.

**Key interfaces:**
- `core/awareness/_resolver.py`: `_newest_file_in_folder(folder) -> str|None` (skip temp
  names, mtime max), ветки `downloaded_file` (журнал → папка) и `newest_in_folder`
  (hint → `_known_folders.folder(hint)` → newest).
- `resolve_reference` (main declaration): добавить kind `newest_in_folder` + пример
  «какой последний файл в загрузках».

**Acceptance criteria:**
- [ ] Журнал пуст, в папке Загрузки есть файлы → `downloaded_file` возвращает новейший по mtime.
- [ ] `newest_in_folder` с hint='documents' → новейший файл в Документах.
- [ ] Временные файлы (`~$*`, `*.tmp`, `*.crdownload`) пропускаются.
- [ ] Если журнал НЕ пуст → возвращается запись журнала (folder-фолбэк не перебивает).
- [ ] Не используется время доступа; читается только одна папка (без рекурсии по всему ПК).
- [ ] Полный `pytest` зелёный (сейчас 118).

**Out of scope:** 008, computer_control, рекурсивный поиск (это `_search`/007).
