## What to build

`_inspectors` внутри пакета `awareness`: определение пути ОТКРЫТОГО документа —
строго по команде, никогда в фоне. Каскад источников (дешёвый → точный):

1. заголовок активного окна (парс имени файла; для VS Code/Notepad обычно достаточно);
2. для Office — COM: `GetActiveObject("Word.Application").ActiveDocument.FullName` /
   `Excel...ActiveWorkbook.FullName` (полный путь; обход нестабильности ROT: повторная
   попытка после активации окна; `pythoncom.com_error` ловится);
3. резолв имени в путь через Windows Recent (`%APPDATA%\Microsoft\Windows\Recent`,
   `.lnk`) и/или поиск (срез 007), с проверкой существования пути.

Все вызовы — на отдельном потоке, с таймаутом и `CoInitialize`; неудача каскада —
честное «не удалось определить», не исключение. Резолвер (004) использует результат
для «документ, который сейчас открыт» / «продолжи работу с документом».

Демо: открыть .docx в Word → «какой документ у меня сейчас открыт?» → полный путь;
затем «продолжи работу с ним» → документ становится целью следующей команды.
