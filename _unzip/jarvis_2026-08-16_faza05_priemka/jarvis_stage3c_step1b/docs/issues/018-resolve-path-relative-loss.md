## Живой репро (2026-07-05) — ПОДТВЕРЖДЁН, потеря данных

Gemini шлёт пути `documents/Мои сочинения`, `Мои сочинения`, `JV`. `_resolve_path`
понимает только ГОЛЫЕ шорткаты (`documents`), поэтому эти пути падают в
`Path(raw)` = ОТНОСИТЕЛЬНЫЙ путь → резолвится от рабочей папки приложения
(`…\mark_xxxv_refactored`). Приложение лежит ПОД Desktop → относительный путь
проходит boundary-проверку (он «внутри Desktop») → файлы молча уезжают внутрь дерева
проекта, невидимо для пользователя.

Проверено:
```
_resolve_path('documents/Мои сочинения') -> documents\Мои сочинения   (relative!)
_resolve_path('Мои сочинения')           -> Мои сочинения             (relative!)
_resolve_path('JV')                      -> JV                        (relative!)
```
Файлы уехали в `…\mark_xxxv_refactored\documents\…`, `…\Мои сочинения`, `…\JV\`.

## Agent Brief

**Category:** bug (data loss)
**Summary:** `_resolve_path` резолвит любой не-шорткат как cwd-относительный путь → файлы уезжают в папку проекта. Нужно: (1) резолвить шорткат+подпуть; (2) НИКОГДА не резолвить относительно cwd — якорить к Desktop.

**Desired behavior:**
- `home` → home; голый шорткат → known folder (как есть).
- **Шорткат + подпуть**: если первый сегмент — известный шорткат (`documents/Мои
  сочинения`, `desktop\proj`), резолвить подпуть ВНУТРИ реальной known-folder.
- **Голый относительный** (`Мои сочинения`, `JV`, `foo/bar`): якорить к **Desktop**
  (пользовательский дефолт), НЕ к cwd приложения. Разделители `/` и `\` оба.
- Абсолютный путь → без изменений.
- Итог: относительные пути больше НИКОГДА не резолвятся под рабочую папку проекта;
  все транскриптные кейсы попадают в видимые места (Desktop\Мои сочинения, Desktop\JV,
  реальные Документы).

**Key interfaces:**
- `actions/file_controller.py::_resolve_path` — единственная правка. `_known_folder`
  уже есть (issue 006). Всё остальное (create/write/move/boundary) наследует фикс.

**Acceptance criteria:**
- [ ] `documents/Мои сочинения` → `<real Documents>\Мои сочинения` (и с `\`).
- [ ] `Мои сочинения` → `<Desktop>\Мои сочинения` (абсолютный, is_absolute()).
- [ ] `JV` → `<Desktop>\JV`.
- [ ] Голый шорткат и абсолютный путь — без изменений.
- [ ] Ни один относительный путь не резолвится под cwd проекта (тест).
- [ ] move с destination `documents/X` кладёт в реальную папку, не в проект (интеграция).
- [ ] Существующие файловые тесты зелёные; полный `pytest` (сейчас 149).

**Out of scope:** авто-уборка уже уехавших тест-файлов (предложить мейнтейнеру
отдельно); модельные недопонимания (Documents vs Desktop) — не код.
