## Agent Brief

**Category:** enhancement
**Summary:** Открывать установленное приложение по (возможно русскому/нечёткому) имени через фаззи-матч по ярлыкам Start Menu — без экранного зрения и без сжигания квоты.

**Desired behavior:**
- Индекс приложений = ярлыки Start Menu (.lnk в
  `%ProgramData%\...\Start Menu\Programs` и `%APPDATA%\...\Start Menu\Programs`):
  имя = имя ярлыка, цель = путь .lnk. Запуск = `os.startfile(lnk)` (надёжно, как клик в
  меню Пуск). Кэш с TTL. Soft (пусто при ошибке/не-Windows).
- **Фаззи-матч** запроса к именам: нормализация (нижний регистр, убрать версии/скобки),
  **транслитерация Cyrillic→Latin** запроса («фотошоп»→«fotoshop»≈«photoshop»,
  «телеграм»→«telegram», «дискорд»→«discord»), совпадение по подстроке/токенам +
  `difflib.SequenceMatcher`. Порог; ниже порога → НЕ запускать, вернуть «не нашёл X,
  похожие: A, B, C?» (топ-3) — под «нечётко произнёс».
- `open_app` расширяется (мейнтейнер разрешил): сначала существующий allowlist-путь
  (без изменений), иначе — фаззи-матч по индексу → запуск найденного ярлыка. Существующее
  поведение allowlist-приложений НЕ меняется.
- Никаких LLM-вызовов в матче (локально, бесплатно). Запуск приложения — low-risk, без
  confirm.

**Key interfaces:**
- `core/awareness/_app_index.py`: `list_shortcuts() -> list[{name,path}]` (seam),
  `_normalize`, `_translit`, `score(query,name)`, `best_match(query, threshold) -> dict|None`,
  `suggestions(query, n) -> list[str]`.
- `actions/open_app.py`: фаззи-фолбэк после allowlist; запуск `_launch_shortcut(path)`
  (шов для тестов).
- Декларация `open_app`: подсказать, что можно открывать любые установленные приложения
  по имени (в т.ч. по-русски).

**Acceptance criteria:**
- [ ] Точное имя («Telegram») → матч ярлыка Telegram.
- [ ] RU→EN транслит: «фотошоп» → «Adobe Photoshop»; «телеграм» → Telegram; «дискорд» → Discord (тесты на фейковом индексе).
- [ ] Подстрока/частично: «photoshop» → «Adobe Photoshop 2024».
- [ ] Ниже порога («asdfqwer») → не запускать, вернуть подсказки (топ-похожие), не зрение.
- [ ] `open_app` фаззи-фолбэк запускает найденный ярлык (шов `_launch_shortcut` подменён в тесте); allowlist-путь не сломан.
- [ ] Матч без LLM; полный `pytest` зелёный (сейчас 134).

**Out of scope:** закрытие приложений (010), computer_control, квота.
