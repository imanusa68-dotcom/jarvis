## Agent Brief

**Category:** bug
**Summary:** У `open_path` нет способа открыть файл в НАЗВАННОМ приложении → на «открой в блокноте» модель уходит в ненадёжные автоклики. Добавить параметр `app` с прямым запуском.

**Current behavior:**
`open_path(path)` умеет только `os.startfile` = приложение по умолчанию. «Открой в
блокноте/Word/…» невозможно детерминированно → модель использует `computer_control`
(экранные клики), что хрупко и катастрофично.

**Desired behavior:**
- `open_path(path, app="")`. Если `app` пуст → как сейчас (`os.startfile`, по умолчанию).
- Если `app` задан → **прямой запуск** `subprocess.Popen([launcher, path])`, где launcher
  разрешается из имени приложения (notepad/блокнот → `notepad.exe`, wordpad → `write.exe`,
  mspaint, vs code → `code`, браузеры, Office…). Переиспользовать имена из `open_app`.
- Никакого экранного зрения/автокликов и без требования SCREEN-тумблера.
- Все защиты 005 сохраняются (boundary + блок-лист исполняемых расширений) — `app` их НЕ
  обходит.
- Если запуск в названном приложении не удался → ЧЕСТНОЕ сообщение об ошибке (НЕ открывать
  молча в приложении по умолчанию — это и путало пользователя). notepad — гарантированно
  надёжен (System32).
- Описание инструмента в `TOOL_DECLARATIONS` подсказывает Gemini: при «открой в <app>»
  звать `open_path(app="<app>")`, а НЕ `computer_control`.

**Key interfaces:**
- `actions/open_path.py`: `_launch(path, app=None)` (шов), `_resolve_launcher(app) -> str`.
- `open_path` читает `parameters["app"]`.
- `main.TOOL_DECLARATIONS[open_path]`: + `app` (STRING, optional) + уточнённое описание.
- SECURITY_POLICY для open_path не меняется (risk=medium).

**Acceptance criteria:**
- [ ] `open_path(path, app="notepad")` → `_launch` вызван с app="notepad"; результат называет приложение.
- [ ] `open_path(path)` (без app) → `_launch(app=None)` → поведение как раньше.
- [ ] `_resolve_launcher("блокнот")`/`("notepad")` → `notepad.exe`.
- [ ] Блок-лист расширений и boundary работают и при заданном `app` (app не обходит защиту).
- [ ] Сбой запуска в приложении → честная ошибка, НЕ тихий open-in-default.
- [ ] Полный `pytest` зелёный (сейчас 113).

**Out of scope:** баг B (последний файл в папке — отдельный амендмент), 008, computer_control.
